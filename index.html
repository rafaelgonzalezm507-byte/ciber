Card 02 / Grammar Foundation

Gerund: Definition

A gerund is a verb form ending in -ing that works as a noun in the sentence.

Formula:

Base Verb + -ing (Encrypting, Hacking, Monitoring)

Examples:

  • Encrypting confidential data prevents unauthorized access.
  • Our SOC team enjoys analyzing security logs.
Card 03 / Grammar Rules

Uses of the Gerund

1. As Subject

Penetration testing requires advanced technical skills.

2. Object of certain verbs

The team finished patching the system vulnerability.

3. After prepositions

He gained access by bypassing two-factor authentication.

4. Common expressions

We are looking forward to upgrading our firewall.

Card 04 / Vocabulary

Verbs Followed by Gerunds

avoidconsiderenjoyfinishkeepmindpractisesuggestrisk
Avoid: System administrators must avoid using default credentials.
Risk: Companies risk losing sensitive records without encryption.
Suggest: The auditor suggested enabling multi-factor authentication.
Card 05 / Grammar Foundation

Infinitive: Definition

An infinitive is the base verb preceded by the particle to.

Formula:

To + Base Form (to secure, to fix, to update)

Examples:

  • Our main objective is to secure user privacy.
  • The developer decided to rewrite the insecure code.
Card 06 / Grammar Rules

Uses of the Infinitive

1. After certain verbs

We hope to eliminate system vulnerabilities soon.

2. Purpose (Why?)

I ran the script to scan for open ports.

3. After adjectives

It is essential to update security definitions daily.

4. After question words

New users learn how to configure their VPN.

Card 07 / Vocabulary

Verbs Followed by Infinitives

agreedecideexpecthopelearnplanpromisewant
Plan: We plan to perform a network security audit this Friday.
Decide: Management decided to implement zero-trust policies.
Promise: The vendor promises to patch zero-day exploits promptly.
Card 08 / Comparison

Gerund vs. Infinitive

Gerund (action focus):

She enjoys testing web applications.

Infinitive (intent focus):

She wants to test web applications.

Same verb, different meaning: STOP

1. Stop + gerund (quit): “They stopped using outdated SSL protocols.” (discontinued it)

2. Stop + infinitive (pause for a purpose): “The specialist stopped to check the server status.” (paused in order to check)

More English Examples in Context

Gerund (verb + -ing)

  • Monitoring the network 24/7 is part of the SOC routine.
  • The analyst recommends updating all endpoints weekly.
  • We cannot risk exposing the database to the internet.
  • They kept scanning the servers until midnight.
  • He is good at detecting phishing emails.
  • Before deploying, the team tested the firewall rules.

Infinitive (to + base verb)

  • Our goal is to protect every user's data.
  • The company decided to adopt a zero-trust model.
  • We installed sensors to detect intrusions early.
  • It is important to back up critical systems daily.
  • The engineer learned how to configure the VPN.
  • They promised to patch the vulnerability today.

Verbs that take BOTH forms (meaning changes)

remember

"Remember to lock the server room" (don't forget) vs "I remember locking it" (a past memory).

stop

"Stop using weak passwords" (quit) vs "Stop to check the logs" (pause for a purpose).

try

"Try resetting the router" (experiment) vs "Try to reset the router" (make an effort).

Preguntas frecuentes (FAQ)

El gerundio termina en -ing y funciona como sustantivo (enjoy testing). El infinitivo usa to + verbo y suele indicar intención o propósito (want to test).

Algunos comunes: avoid, consider, enjoy, finish, keep, mind, practise, risk, suggest. Ej.: “She avoids opening suspicious links.”

agree, decide, expect, hope, learn, plan, promise, want. Ej.: “We plan to perform a security audit.”
